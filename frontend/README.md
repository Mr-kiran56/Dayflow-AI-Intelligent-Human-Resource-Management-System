# DayFlow AI Frontend

Intelligent Human Resource Management System Frontend built with React, Vite, TailwindCSS, and Lucide React Icons.

## Setup & Running Locally

```bash
npm install && npm run dev
```

Runs local development server on `http://localhost:5173`.

## Environment Configuration

Configure `VITE_API_BASE_URL` in `.env`:

```env
VITE_API_BASE_URL=http://localhost:8000/api/v1
```
